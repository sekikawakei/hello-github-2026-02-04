# hello-github-2026-02-04
CursorとGitHubの連携の手順を書いていきます
まずはブランチを作成します。
ブランチは（後ほど詳細記載・・・）

ここからは実際のドキュメントの操作についてです。

まずは、
①Cursorの画面中央の「エディタ」でドキュメントに編集します。

次に、
②Cursorの左カラムの「変更」を見て「＋」にカーソルを合わせてホバーで現れる「変更をステージ」を押下します。
③押下後に「変更」が「1」→「0」になったことを確認します。

※この①〜③の操作を通して「ステージ」に移行されたものだけが「コミット」の対象になります。

それではそもそも「コミット」とは何かなのですが・・・
「今の状態をきちんと保存すること」と感覚的に捉えてもらえれば良いです。

もう少し概念的に言えば・・・
Gitに対して「ここまでの変更は、ひと区切りやで」って宣言する行為です。

流れとして
エディタで文字を書く→ステージに入れる→コミットする→プッシュする/プルする
という一連の流れになります。プッシュ/プルするためには必要な作業です。
